# Dataset

Набор данных хранится в `data/raw/` и содержит 3 класса:

- `class1` - бабочки, 70 изображений.
- `class2` - собаки, 98 изображений.
- `class3` - змеи, 116 изображений.

Задача проекта - классифицировать входное изображение животного в один из трех известных классов: бабочка, собака или змея.

## Метод Сбора

Изображения собраны пользователем самостоятельно и разложены по подпапкам классов. Для улучшения устойчивости модели желательно, чтобы внутри каждого класса были разные ракурсы, фоны, масштабы объектов и условия освещения.

## Разбиение

Скрипт `experiments/train.py` создает `data/processed/train` и `data/processed/val` в пропорции 80/20. Если исходный датасет был изменен, нужно запускать обучение с флагом `--force-resplit`, чтобы старое разбиение не использовалось повторно.

## Предобработка

Во время обучения используется:

- изменение размера до `224x224`;
- аугментации train-выборки: `RandomHorizontalFlip`, `RandomRotation(15)`, `ColorJitter`;
- преобразование в тензор;
- нормализация ImageNet: `mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`.

Валидация и Gradio-приложение используют resize до `224x224`, преобразование в тензор и такую же нормализацию ImageNet. Это снижает расхождение между обучением и инференсом.

## Ограничения

Классы немного несбалансированы: `class1` содержит меньше изображений, чем `class2` и `class3`. В `train.py` для этого включены веса классов в `CrossEntropyLoss`. Для более честного сравнения моделей можно дополнительно сократить каждый класс до одинакового числа изображений или дособрать изображения для меньших классов.
