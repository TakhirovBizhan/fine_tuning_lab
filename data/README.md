# Dataset

Набор данных находится в `data/raw/` и содержит 3 класса:

- `class1` - изображения бабочек.
- `class2` - изображения собак.
- `class3` - изображения змей.

В каждом классе не менее 30 изображений. Задача проекта - классифицировать изображение животного в один из трех классов.

Перед обучением `experiments/train.py` создает разбиение `data/processed/train` и `data/processed/val` в пропорции 80/20, если в `data/processed/` еще нет изображений.

Предобработка во время обучения:

- изменение размера до `224x224`;
- аугментации для train: горизонтальное отражение, поворот до 15 градусов, небольшой `ColorJitter`;
- преобразование в тензор;
- нормализация ImageNet: `mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`.

Приложение `app/app.py` использует тот же resize и ту же нормализацию для ONNX-инференса.
